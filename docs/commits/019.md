# Overview del incremento 019 — Encuesta de satisfacción y métricas

Fecha: 2026-11-05. Rama prevista: `feature-metricas`. Mensaje propuesto: `feat: add order satisfaction survey and business metrics`.
Estado: **en revisión** (código, pruebas y documentación listos; pendiente de tu revisión antes de confirmar, tarea C19-12). La API pasa de 50 a **53 operaciones**.

## Resultado

| Área             | Cambio                                                                                                                                                                                                                                    |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Encuesta         | `POST /orders/:id/survey` (solo `cliente`): `rating` 1 a 5 y `comment` opcional (hasta 300). Un pedido `entregado` admite una sola respuesta, no editable. `404` si es ajeno o no existe; `409` si no está entregado o ya fue respondido. |
| Vista del pedido | `survey` (`{rating, comment, createdAt}` o `null`) en el pedido para cliente, admin y operador.                                                                                                                                           |
| Listado          | `GET /surveys` (solo `admin`): paginado, la más reciente primero, filtros `rating`, `from`, `to` (días de Colombia); trae cliente, zona y número de pedido.                                                                               |
| Métricas         | `GET /metrics` (solo `admin`), con `from`/`to` (por defecto 30 días, máximo 366) y `zoneId`: ventas (con serie diaria), margen y costo variable (total y por categoría), tiempos de despacho, satisfacción, recompra y resultados.        |
| Reglas           | Venta = pago `aprobado` (cuenta `no_entregado`, no la cancelación). Costo = el guardado en cada línea. «A tiempo» = reparto (`en_camino` → `entregado`) de 15 minutos o menos. Días en hora de Colombia (UTC−5).                          |
| Consistencia     | El informe se calcula en una transacción `REPEATABLE READ`: todas las secciones ven los mismos datos.                                                                                                                                     |
| Migración        | `1791244809000-surveys`: tabla `order_surveys` (`UNIQUE(order_id)`, CHECK de calificación y comentario). `down()` aborta si hay respuestas.                                                                                               |
| Otros            | `Cache-Control: no-store` en `/surveys` y `/metrics`; eliminar un cliente con encuestas responde `409`.                                                                                                                                   |
| Fuera de alcance | Editar o borrar una respuesta, exportar a CSV, métricas por producto, qué hacer con los `no_entregado`.                                                                                                                                   |
